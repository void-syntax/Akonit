# Signal Radar — Инструкция

## Быстрый старт

Двойной клик на `start.bat` или запусти в PowerShell. При первом старте
создаются локальное Python-окружение и файл `backend/.env` с безопасными
настройками, затем устанавливаются зависимости. Следующие запуски используют
уже установленные пакеты и твои настройки:

```powershell
.\start.ps1
```

Система запустит:
- **Backend API** на http://localhost:8000
- **Worker scheduler** — сбор и анализ сигналов
- **Frontend** на http://localhost:3000
- Откроет дашборд в браузере

Для ручного запуска без Docker смотри раздел **Starting it by hand** в
`README.md`.

## Реальный доступ к соцсетям

Публичные и официальные API дают разные уровни покрытия. Они не открывают
«весь интернет»: доступ ограничивают ключи, одобрение приложений, квоты и сами
платформы.

- **X:** добавь свой `X_API_BEARER_TOKEN` в `backend/.env`. Официальный поиск
  ищет свежие посты по словам активных радаров. Чтение платное; по умолчанию
  установлен предел 100 постов в сутки. Платный поиск запускается раз в три
  часа, чтобы не исчерпать лимит за ночь; публичная лента трендов обновляется
  чаще. Верхний предел расходов — около $0.50/сутки по текущей цене $0.005 за
  пост. Проверь тариф и баланс в X Developer Console. Чтобы
  полностью выключить платное чтение, установи `X_POSTS_DAILY_READ_LIMIT=0`.
- **Reddit:** при наличии одобренного Reddit-приложения укажи
  `REDDIT_CLIENT_ID` и `REDDIT_CLIENT_SECRET`. Сборщик получает короткоживущий
  OAuth-токен, опрашивает новые посты в сообществах и продолжает использовать
  публичные резервные источники без ключей. Для внешнего приложения Reddit
  требует одобрение доступа и соблюдение условий Data API; зарегистрируй
  приложение через актуальный процесс Reddit. Также укажи в
  `REDDIT_USER_AGENT` название приложения и свой настоящий Reddit username.
- **TikTok:** широкий Research API требует одобрения и доступен подходящим
  исследовательским организациям. Отдельный Commercial Content API доступен
  заявителям после одобрения; фильтр по стране автора пока включает страны ЕЭЗ,
  кроме Великобритании и Швейцарии. Для него укажи `TIKTOK_COMMERCIAL_CLIENT_KEY` и
  `TIKTOK_COMMERCIAL_CLIENT_SECRET`. Без этих разрешений приложение видит
  только часть публичных трендовых данных; оно не получает все публикации.
- **YouTube и Instagram:** официальное расширение также зависит от API-ключа,
  разрешений и квот платформы.

Ключи вводи только в локальный `backend/.env`, не присылай их в чат и не
публикуй в GitHub.

## Как подключить больше публичных источников

- **Любой сайт, который публикует RSS/Atom:** добавь URL в `EXTRA_RSS_FEEDS`
  в `backend/.env`, через запятую. Можно указать до 10 лент; программа читает
  их по очереди и ограничивает размер каждой выдачи. Для сайтов без RSS можно
  отдельно развернуть RSS-Bridge и добавить созданные им URL. Публичные общие
  экземпляры мостов могут пропасть или ограничить запросы — надёжнее свой.
- **Bluesky:** публичный Jetstream WebSocket присылает новые посты без входа.
  Signal Radar слушает короткими окнами до 12 секунд, чтобы не держать постоянное
  соединение и не заливать базу всем потоком.
- **Mastodon:** публичные тренды и статусы собираются с выбранных экземпляров.
  Можно задать список до 6 доменов в `MASTODON_INSTANCES`. Каждый сервер может
  отключить публичные ленты или ограничить поиск; это не глобальный поиск по
  всей федерации.

Неофициальные обходы логина, CAPTCHA и антибот-защит я в проект не добавляю:
они нестабильны, быстро ломаются и могут привести к блокировке источника.
Открытые страницы, публичные фиды и разрешённые платформенные API остаются
рабочими вариантами.

## Нагрузка на слабом компьютере

Сборщик запускает источники по их собственному интервалу (например, раз в
15–60 минут), даже если сам планировщик проверяет очередь чаще. Одновременно
выполняется не более 4 сетевых запросов, за один источник обрабатывается до 25
событий, а необязательная AI-классификация выключена по умолчанию. Это помогает
сохранять быстрый поиск сигналов без загрузки AI-модели в память.

### Локальная AI-классификация

Laya не является обязательной зависимостью проекта. Классификатор остаётся
выключенным по умолчанию и не загружает модель при запуске API. Если пакет Laya
и её checkpoint уже установлены локально, классификацию можно включить через
`AI_CLASSIFICATION_ENABLED=true` в `backend/.env`. При первом анализе модель
будет загружаться на CPU; сборщик ограничивает параллелизм одним потоком. Если
checkpoint отсутствует, система использует лёгкие правила и не скачивает модель
автоматически. Для слабого ноутбука оставляй настройку выключенной.

Оценка активности, метка приоритета и классификатор шума — эвристики, пока
проект не накопит проверенные пользователем исходы. Они не являются
калиброванными вероятностями, инвестиционными рекомендациями или прогнозом
доходности. Брифинг формируется по имеющимся полям и ссылкам, а не генеративной
моделью; проверяй первоисточники и даты публикации.

Эти параметры можно изменить в `.env`:

```env
HTTP_MAX_CONCURRENCY=4
COLLECTION_MAX_EVENTS_PER_SOURCE=25
AI_CLASSIFICATION_ENABLED=false
SOURCE_COOLDOWN_SECONDS=300
```

Для ранних и более надёжных сигналов сначала настройте радар под конкретную
тему, страну и ключевые слова. Затем проверьте в панели источников, какие
источники действительно приносят данные. Instagram и TikTok требуют разрешённый
доступ платформы для соответствующих трендов; X публикации доступны только
через одобренный API-тариф. Без этих доступов приложение продолжает собирать
Bluesky, Mastodon, Reddit и публичные новостные/тематические источники, а закрытые
соцсети помечает как требующие учётные данные. Сильный сигнал должен подтверждаться
несколькими независимыми источниками и иметь свежую историю роста; один большой
счётчик просмотров сам по себе не доказывает ранний тренд.

## Автозапуск при включении ноутбука

Один раз запусти от имени администратора:

```powershell
# ПКМ на PowerShell -> Запуск от имени администратора
.\install_autostart.ps1
```

После этого Signal Radar будет стартовать автоматически при входе в Windows.

Чтобы убрать автозапуск:

```powershell
Unregister-ScheduledTask -TaskName "SignalRadar"
```

## Telegram-бот

1. В настройках Signal Radar вставь токен своего бота, созданного через **@BotFather**. Приложение проверит его и сохранит зашифрованным.
2. Открой бота в Telegram и нажми **Start**.
3. Отправь боту `/start`, нажми **Find my chat**, затем **Save chat ID**.
4. Нажми **Send test**. Когда сообщение придёт, включи **Alerts ON**.

При первом запуске `start.bat` создаёт локальный ключ шифрования в `backend/.env`. Не удаляй и не публикуй этот файл: без него приложение не сможет расшифровать сохранённый токен после перезапуска. Токен и ключ игнорируются Git.

### Команды бота

| Команда | Что делает |
|---------|-----------|
| `/top` | 5 сильнейших сигналов |
| `/new` | Последние новые сигналы |
| `/rising` | Растущие тренды |
| `/breakout` | Критические тренды 🚨 |
| `/status` | Статус системы |
| `/radars` | Твои радары |
| `/mute 2` | Заглушить алерты на 2 часа |
| `/help` | Помощь |

## Структура проекта

```
Project/
├── start.bat              ← двойной клик для запуска
├── start.ps1              ← скрипт запуска
├── stop.ps1               ← скрипт остановки
├── status.ps1             ← проверка статуса
├── install_autostart.ps1  ← установка автозапуска (1 раз)
├── backend/               ← FastAPI + worker
│   ├── .env               ← настройки и токены
│   ├── .venv/             ← Python виртуальное окружение
│   └── app/
│       ├── main.py        ← API сервер
│       └── workers/       ← сборщики сигналов
├── frontend/              ← Next.js дашборд
└── logs/                  ← логи (создаётся автоматически)
    ├── startup.log
    ├── backend.log
    ├── backend_err.log
    ├── worker.log
    ├── worker_err.log
    ├── frontend.log
    └── frontend_err.log
```

## Решение проблем

**Backend не запускается:**
```powershell
# Проверь лог ошибок
Get-Content .\logs\backend_err.log -Tail 20
```

**Frontend не запускается:**
```powershell
# Проверь что npm установлен
npm --version
# Проверь лог
Get-Content .\logs\frontend_err.log -Tail 20
```

**Порт занят:**
```powershell
# Узнай кто занимает порт 8000
netstat -ano | findstr :8000
# Убей процесс
.\stop.ps1
```

**Переустановка зависимостей:**
```powershell
# Backend
cd backend
.\.venv\Scripts\pip install -r requirements.txt

# Frontend
cd frontend
npm install
```
